# Yijie Pan — personal website

Source for my academic website, built with React, Vite, and Tailwind CSS.
Pushing to `main` builds and deploys the site to GitHub Pages via
`.github/workflows/deploy.yml`.

Papers, notes, and talks are listed in the `projects`, `notes`, and `talks`
arrays at the top of `src/App.tsx`; note PDFs live in `public/notes/`.

## Run locally

Requires Node.js.

```bash
npm install
npm run dev
```
